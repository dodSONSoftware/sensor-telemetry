## Key Features Implemented

### JSON Output Format
```json
{
  "timestamp": "2026-07-19T23:48:23.486-05:00",
  "level": "info",
  "service": "sensor-telemetry",
  "event": "configuration_loaded",
  "logType": "service",
  "message": "Configuration loaded successfully",
  "module": "index.ts",
  "function": "readConfigurationFile",
  "source": "./dist/config.yml",
  "configurationKeyCount": 8,
  "environment": "development",
  "version": "1.2.2"
}
```

### Log Type Classification
- `service`: Internal backend lifecycle and infrastructure
- `sensor`: Events generated by or describing specific sensors
- `audit`: State-changing operations initiated by users/admins

### Error Severity
- `standard`: Ordinary errors requiring attention
- `critical`: Immediate operator attention required

### Secret Redaction
Automatically redacts: password, passwd, wifi-password, authorization, cookie, token, accessToken, refreshToken, secret, clientSecret, apiKey, privateKey

### Originator Normalization
Converts `module/function` format to structured `{ module: "module", function: "function" }`
